A week building ORPHANED: letting Claude write the game, keeping it honest

ORPHANED is a tiny always-on-top window with a pixel creature living inside it. It grows on real-world time whether the program is open or not, it fights hostile “programs” when you feel like picking a fight, and if you neglect it long enough it dies — permanently — and gets written into an archive of every version that came before. I spent about a week building it. But the part worth writing down isn’t the game. It’s this: I can’t really write a program this size on my own, so I didn’t. Claude wrote almost all of the code. My job was deciding what the thing should do, running it, playing it, and catching it when it quietly drifted off the rails.
